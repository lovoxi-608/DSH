口琴助手 · 使用说明
====================

一、网页版（浏览器）
----------------
1. 打开「口琴谱解析」页面。
2. 把音频文件（wav / mp3 等）拖入上传区，或点击选择文件；支持试听。
3. 选择解析格式：目前提供「口琴简谱 · 三角洲口琴体系」，另有格式位预留。
4. 点击「开始解析」，等待进度完成。
5. 谱面以口琴键位卡片展示在结果区：
   - 键位：z x c v b n m = do re mi fa sol la si（中音），逗号 = 高音 do
   - 鼠标修饰键：左键 = 低八度，右键 = 高八度，中键 = 升半音
   - 可演奏范围 = 基准八度 ±1 八度 + 高高音 do / #do（右键+逗号，再按中键=#）
   - 音符卡片颜色含义：
       灰 = 基准（不用按修饰键）
       蓝 = 低八度（左键）
       红 = 高八度（右键）
       绿 = 升半音（中键）
       青 = 低八度+升半音（左键+中键）
       橙 = 高八度+升半音（右键+中键）
   - 超出可演奏范围的音符会标记为「跳过」
6. 移调：用「基准八度」面板选择 C3~C7 或自动，整曲随之重映射。
7. 试听：点击任意音符卡片试音；「试听口琴演奏」可播放整曲。
   试听音色为真实口琴采样（Hohner Silverstar，CC0 公共领域）。
   想用自己的音色：把文件放进下方「音色目录」填写的路径即可自动替换每个键位的试听音，
   文件名规则：z.mp3 x.mp3 c.mp3 v.mp3 b.mp3 n.mp3 m.mp3 comma.mp3（支持 .mp3/.wav/.ogg）。
8. 测试台：「口琴按键测试台」与游戏一致，可点击虚拟键或直接按键盘实时试音，
   按住左键=低八度、右键=高八度、中键=升半音；「中音 do」可切换 C3~C7。
9. 导出：点击「导出曲谱」，下载 txt 曲谱文件，供口琴助手小程序加载。

二、口琴助手小程序（源码版 kouqin-helper.py）
--------------------------------------------
悬浮于游戏画面之上的辅助小工具，用来告诉你「现在该按哪个键、带什么修饰」。
- 运行方式：安装 Python 3.10+ 后执行 `python kouqin-helper.py`（仅用标准库，无第三方依赖）。
- 圆角毛玻璃质感、半透明置顶悬浮：默认 94% 不透明度，鼠标按住面板空白处可拖动，
  拖动右下角圆角柄可缩放；右上滑杆可调透明度。
- 纯视觉引导、无发声：只显示按键提示，不影响游戏声音。
- 鼠标被游戏获取时面板自动穿透：开启「穿透」后，鼠标点击会直接穿过面板落到游戏上，
  面板不会挡住游戏操作；按 Shift+F10 或点「穿透」按钮开关。

三、小程序功能
------------
1. 加载曲谱：点「＋ 添加」或按 Shift+F11 选择网页导出的 txt 文件。
2. 演奏：点 ▶ 或选中曲目后自动开始，音符从右侧轨道顶部下落，命中线亮起时按下对应键。
3. 键位：z x c v b n m ，对应 8 个吹孔；
   修饰键（鼠标）：左键 = 低八度，右键 = 高八度，中键 = 升半音。
   「检测到」提示会显示当前音符需要的按键与修饰方式（颜色也提示：蓝=低八度、红=高八度等）。
4. 基准八度：左侧「基准八度」面板可整曲移调（谱面 / C3~C7），网页导出的谱自带基准八度也会正确显示。

四、热键一览（均需按住 Shift）
--------------------------
Shift+F6     隐藏/显示面板
Shift+F7     下一首曲目
Shift+F8     锁定/解锁布局（锁定后不可拖动、不可缩放）
Shift+F9     从头重来
Shift+F10    面板穿透开/关（游戏内鼠标不挡）
Shift+F11    添加曲谱（打开文件选择）
Ctrl+Alt+Q   退出小程序

五、常见问题
----------
Q: 打不开 / 报错？
A: 需安装 Python 3.10+（64 位），在命令行进入本目录执行：python kouqin-helper.py。
   杀毒软件可能拦截 Python 创建的悬浮窗，选择「允许」即可。

Q: 游戏全屏时面板不显示？
A: 面板是置顶窗口，全屏独占游戏（DXGI 全屏）可能盖住它；把游戏设为「无边框窗口/窗口化」
   即可悬浮。开启穿透后鼠标点击会穿过面板。

Q: 曲谱文件格式？
A: 网页导出格式（v1.1，三角洲口琴体系）：
   # 口琴曲谱 v1.1（三角洲口琴体系 · 可用「口琴助手」小程序加载）
   曲名: xxx
   BPM: 90
   基准八度: 5
   z 基准 0.00 0.50
   b 低八度 0.50 0.50
   , 高八度+升半音 1.00 0.60
   ...每行 = 键 修饰 开始秒 时长秒；修饰可用：基准/低八度/高八度/升半音/低八度+升半音/高八度+升半音。
   旧版 v1.0 谱（本音/降调/升调/半+降/半+升）也可加载，会自动近似转换。
