# 口琴音色与操控基础值

> **用途**：本表是「音频 → 游戏口琴谱」解析器的基准参照值。解析时把检测到的音高（MIDI 音高值）按本表映射到口琴键位（`z x c v b n m ,`）与鼠标修饰（左键 / 右键 / 中键），并判断该音是否在可演奏范围内。
>
> 依据《三角洲行动》口琴体系（HarpAutoPlayer NoteMapper + 口琴钢琴测试台），与网页「口琴谱解析」应用完全一致。

## 一、基础音 1 ~ 8（键盘键位）

| 基础音 | 唱名 | 键位 | 半音号 pc | 说明 |
|:---:|:---:|:---:|:---:|---|
| **1** | do | `z` | 0 | 基准八度的主音 |
| **2** | re | `x` | 2 | |
| **3** | mi | `c` | 4 | |
| **4** | fa | `v` | 5 | |
| **5** | sol | `b` | 7 | |
| **6** | la | `n` | 9 | |
| **7** | si | `m` | 11 | |
| **8** | 高音 do | `,`（逗号） | 0（八度 +1） | 比基准高一个八度的 do |

> 键位即钢琴白键的 do re mi fa sol la si；八度内缺失的黑键（#do #re #fa #sol #la）通过**按住中键**获得（见第三节）。

## 二、音色值（MIDI 音高）定义

### 2.1 音高公式

```
音高 midi = (八度号 + 1) × 12 + 半音号 pc

其中：
- 基准八度 B：中音 do 所在的八度（B ∈ 3..7，即 C3..C7，对应 MIDI 48/60/72/84/96 的 C）
- 各键半音号 pc：z=0  x=2  c=4  v=5  b=7  n=9  m=11
- 逗号键：半音号 pc=0，且八度号自动 +1
- 升半音（按住中键）：音高再 +1
```

## 三、如何控制发出的音色（升降调操控）

### 3.1 三个鼠标修饰键

| 修饰键 | 作用 | 音高变化 |
|:---:|---|---|
| **左键**（按住） | 整排**降到低八度** | −12 半音 |
| **右键**（按住） | 整排**升到高八度** | +12 半音 |
| **中键**（按住） | **升半音**（黑键 #do #re #fa #sol #la） | +1 半音 |

### 3.2 六种有效状态组合

| 状态 | 修饰 | 音高变化 | 网页颜色 |
|:---:|---|---|:---:|
| 基准 | 不按修饰键 | 0 | 灰 |
| 低八度 | 按住左键 | −12 | 蓝 |
| 高八度 | 按住右键 | +12 | 红 |
| 升半音 | 按住中键 | +1 | 绿 |
| 低八度 + 升半音 | 左键 + 中键 | −11 | 青 |
| 高八度 + 升半音 | 右键 + 中键 | +13 | 橙 |

### 3.3 按键到最终音高的计算

```
最终音高 = (B + slot + 逗号偏移) × 12 + pc + sharp

slot      = 0（基准）/ −1（左键低八度）/ +1（右键高八度）
逗号偏移  = 逗号键为 +1，其余键为 0
pc        = 键位半音号（z=0 .. m=11；逗号=0）
sharp     = 按住中键为 1，否则 0
```

**示例**（B=5）：
- `z` = (5+0)×12+0+0 = **72（C5）**
- 左键 + `z` = (5−1)×12+0 = **60（C4）**
- 右键 + `m` = (5+1)×12+11 = **95（B6）**
- 中键 + `x` = 74+1 = **75（D#5）**
- 右键 + `,` = (5+1+1)×12 = **96（C7 高高音 do）**
- 右键 + 中键 + `,` = 96+1 = **97（C#7 高高音 #do）**

## 四、可演奏范围（解析判定基准）

```
对某个音高 midi：
  八度差 d = 音高所在八度 − 基准八度 B

  可演奏（InRange = true）：
    d = −1（低八度区）   → 该八度的 z..m 全部 7 个自然音
    d =  0（基准区）     → 该八度的 z..m + 逗号（高音 do）
    d = +1（高八度区）   → 该八度的 z..m 全部 7 个自然音
    d = +2（高高音区）   → 仅 do（pc=0）与 #do（pc=1），即「右键+逗号」±中键

  不可演奏（InRange = false）：
    其余任何音高 → 解析器标记为「跳过」，不生成按键
```

**范围边界**（所有 B 通用，半音号 pc 为音高的 mod 12）：

| 音区 | 键 | 半音号范围 |
|:---:|:---:|:---:|
| 低八度区 | z..m | pc ∈ {0,2,4,5,7,9,11} |
| 基准区 | z..m 与 `,` | 同上 + 高音 do |
| 高八度区 | z..m | pc ∈ {0,2,4,5,7,9,11} |
| 高高音区 | `,` | pc ∈ {0, 1} |

**需要中键的半音号**（黑键）：`#do=1  #re=3  #fa=6  #sol=8  #la=10`

## 五、基准八度 B 的选择

### 5.1 自动选择（AutoBaseOctave）

```
遍历 B ∈ [旋律最低八度 .. 旋律最高八度]：
  统计在基准 B 下「可演奏」的音符数量
取可演奏数量最多的 B；
若平局，取最接近旋律平均八度的 B。
```

### 5.2 手动选择

网页「基准八度」面板与测试台「中音 do」下拉均可手动指定 `B ∈ 3..7`（C3~C7）；小程序加载曲谱时读取文件中的「基准八度:」行，未写则默认 B=4（C4）。

## 附：解析器实现要点（与本表对应）

| 步骤 | 依据 |
|---|---|
| 1. 音高检测 | 音频帧 → 频率 → MIDI（`midi = 69 + 12·log₂(f/440)`） |
| 2. 选基准 B | 第五节自动选择 / 手动 C3~C7 |
| 3. 判定可演奏 | 第四节 `reachable(pitch, B)` |
| 4. 映射键位 | `keyOfPitch`：pc∈{0,2,4,5,7,9,11} 直接对应 z..m；pc∈{1,3,6,8,10} 降半音取自然键并标记中键 |
| 5. 标记修饰 | `slot` = 八度差（−1 左键 / 0 基准 / +1 右键），`sharp` = 是否需中键 |
| 6. 导出谱 | 每行：`键 修饰 开始秒 时长秒`，修饰词 = 基准/低八度/高八度/升半音/低八度+升半音/高八度+升半音 |

> 频率 → MIDI 换算、MIDI → 音名换算均为标准 12-TET（A4=440Hz）。
